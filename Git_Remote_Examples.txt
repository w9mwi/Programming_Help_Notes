CREATE A NEW REMOTE GIT REPOSITORY
==================================

You can create a new remote git repository on github.com or bitbucket.org
via a web browser.  You can also create a new remote git repository on
github.com or bitbucket.org from the command line on your local computer
by using the linux "curl" command.

This tutorial only covers creating a new remote git repository via
a web browser.


1)
Navigate to your user account on github.com or bitbucket.org via
a web browser and create a new reposirory named My_Git_Repo.

2)
On your local computer, open a command-line console window and create
a new folder named "My_Git_Repo".  Next, navigate into that folder
using the "cd" command and run the following command.

$ git init -b main

Confirm the above command created a ".git" folder within the My_Git_Repo folder.

3)
Create the files that will reside in this new repository.  Once you're ready
to add these new files into the repository, run the following two commands.

$ git add .
$ git commit -m "A comment describing the new files committed."
