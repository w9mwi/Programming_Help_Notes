CREATE A NEW REMOTE GIT REPOSITORY
==================================
You can create a new remote git repository on github.com or bitbucket.org
via a web browser.  You can also create a new remote git repository on
github.com or bitbucket.org from the command line on your local computer
by using the Linux "curl" command.

This tutorial only covers creating a new remote git repository via
a web browser.


1) Navigate to your user account on github.com or bitbucket.org via
   a web browser and create a new reposirory named My_Git_Repo and
   leave it empty.

2) On your local computer, open a command-line console window and create
   a new folder named "My_Git_Repo".  Next, navigate into the My_Git_Repo
   folder and run the following command.
   $ git init -b main   ("-b main" creates a git branch named "main")

   Confirm the above command created a ".git" folder within the My_Git_Repo folder.

3) Create some files that will reside in your My_Git_Repo folder.  Then,
   add and commit those files into your local repository by running the
   following commands.
   $ git add .
   $ git commit -m "A comment describing the new files committed."
   $ git status  (Confirm it returns the following 2 lines of text.)
   On branch main
   nothing to commit, working tree clean

4) Run the following command.
   $ git remote add origin git@github.com:w9mwi/My_Git_Repo.git

   The above command updates the hidden file .git/config  inside the My_Git_Repo folder.
   It does not connect to the internet or transfer any data.

5) Run the following command:
   $ git push -u origin main

   This command uploads your local commits from the main branch to the remote repository
   nicknamed "origin", and permanently links the two branches together.  Once this command
   finishes, your files and commit history will appear in the remote My_Git_Repo repository
   located on the github.com server.

   In the above "git push" command...
   * "origin" designates the nickname you of the remote server.
   * "main" designates the branch pushed to the remote github server.
   * The -u flag permanently links the connection between your local
     main branch and the remote "origin/main" branch so the next
     time you need to run the "git push" command, you can just run
     "git push" without specifying any flags or arguments.
