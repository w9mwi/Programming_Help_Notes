CLONE A REMOTE GIT REPOSITORY TO YOUR LOCAL GIT REPOSITORY
==========================================================

NOTE - A remote repository is usually located on a remote server,
       not on your local computer.  However, assume you have two git
       repositories on your local computer named Repo_1 and Repo_2.
       If you're currently working in the Repo_1 folder/repository,
       the Repo_2 folder/repository is considered a remote repository
       from your Repo_1 folder/repository,even though they're both
       contained on your local computer.  Therefore, the "git clone"
       command doesn't require an internet connection.  You can clone
       another repository stored elsewhere on your local computer or
       packaged inside a git .bundle archive file.

The git clone command creates a complete local copy of an existing Git repository
on your computer.  Beyond simply downloading the project files, "git clone" does
the following:

* Sets up a hidden folder named ".git" that contains the entire commit history.
* Checks out the default branch.
* Automatically creates a remote bookmark named "origin" pointing back to the
  remote (source) repository.

Assume the following...

* You have a respoitory on github.com named: My_Git_Repo
* Your github.com username is: w9mwi
* On your local computer, there exists no folder named: /home/tjb/My_Git_Repo
* Your console window is pointed to folder name: /home/tjb

From your local /home/tjb folder, if you run the following command, a
new folder named "/home/tjb/My_Git_Repo" will get created, which will
contain the repository cloned from: github.com/w9mwi/My_Git_Repo

$ git clone git@github.com:w9mwi/My_Git_Repo.git

NOTE: If the git repository is located on bitbucket.org, use ths command instead.
      $ git clone git@ssh.bitbucket.org:iwm9w/my-git-repo.git

If you want the cloned repository to exist in a folder with a different
name (i.e., /home/tjb/My_Cloned_Repo), run the following command instead.

$ git clone git@github.com:w9mwi/My_Git_Repo.git  My_Cloned_Repo

To be safe, make certain the folder n your local directory that will hold
the cloned repository (i.e., /home/tjb/My_Git_Repo) either doesn't exist,
or it is empty.

By default, the above two clone commands will designate "origin" as the name
of the remote github.com repository.  So when you run the the "git fetch",
"git pull", or "git push" commands later, they will work without you having
to specify a branch name in those commands.

By default, Git checks out the repository's default branch, which is usually
named "main" or "master".  To clone a different branch from a remote repository
specify the -b flag, followed by the branch name, as in the following command.

$ git clone -b branchName git@github.com:w9mwi/My_Git_Repo.git

Running this command will also designate "origin" as the branch name you
cloned, so when you run the the "git fetch", "git pull", or "git push"
commands later, they will work without you having to specify a branch name
in those commands.

If you need only the latest version of the code, instead of a history of every
commit made, you can save time and disk space by running a "shallow clone".
To do that specify the --depth flag as in the following command.

git clone --depth 1 git@github.com:w9mwi/My_Git_Repo.git

The "--depth 1" flag downloads only the single most recent
commit instead of the entire project history.



CREATE A NEW REMOTE GIT REPOSITORY
==================================
You can create a new remote git repository on github.com or bitbucket.org
via a web browser.  You can also create a new remote git repository on
github.com or bitbucket.org from the command line on your local computer
by using the Linux "curl" command.

This tutorial only covers creating a new remote git repository via
a web browser.


1) Navigate to your user account on github.com or bitbucket.org via
   a web browser and create a new reposirory named My_Git_Repo and
   leave it empty.

2) On your local computer, open a command-line console window and create
   a new folder named "My_Git_Repo".  Next, navigate into the My_Git_Repo
   folder and run the following command.
   $ git init -b main   ("-b main" creates a git branch named "main")

   Confirm the above command created a ".git" folder within the My_Git_Repo folder.

3) Create some files that will reside in your My_Git_Repo folder.  Then,
   add and commit those files into your local repository by running the
   following commands.
   $ git add .
   $ git commit -m "A comment describing the new files committed."
   $ git status  (Confirm it returns the following 2 lines of text.)
   On branch main
   nothing to commit, working tree clean

4) Run the following command.
   $ git remote add origin git@github.com:w9mwi/My_Git_Repo.git

   The above command updates the hidden file .git/config  inside the My_Git_Repo folder.
   It does not connect to the internet or transfer any data.

5) Run the following command:
   $ git push -u origin main

   This command uploads your local commits from the main branch to the remote repository
   nicknamed "origin", and permanently links the two branches together.  Once this command
   finishes, your files and commit history will appear in the remote My_Git_Repo repository
   located on the github.com server.

   In the above "git push" command...
   * "origin" designates the nickname you of the remote server.
   * "main" designates the branch pushed to the remote github server.
   * The -u flag permanently links the connection between your local
     main branch and the remote "origin/main" branch so the next
     time you need to run the "git push" command, you can just run
     "git push" without specifying any flags or arguments.
